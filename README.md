# E-handelsanalys

## Projektbeskrivning
Projektet går ut på att ta fram ett beslutsunderlag inför en kampanj för en fiktiv e-handelsplattform.

## Miljö
- Python 3.14.7
- Jupyter Notebook
- Pandas
- Matplotlib
- (se `requirements.txt`)

## Kom igång

1. Klona repot:
```bash
git clone https://github.com/Ivartingbrant/Grupparbete-Python.git
cd Grupparbete-Python
```
2. Skapa och aktivera virtuell miljö:
```bash
python -m venv .venv
```
3. Installera beroenden:
```bash
python -m pip install -r requirements.txt
```
